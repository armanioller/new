# RPG Low-Poly Three.js

Um jogo de RPG 3D estilo low-poly desenvolvido com Three.js.

## Como Jogar Online
O jogo é publicado automaticamente no GitHub Pages.
1. Vá para as configurações do seu repositório no GitHub.
2. Na aba **Pages**, verifique se a fonte está configurada para **GitHub Actions**.
3. O link estará disponível assim que o workflow for concluído.
